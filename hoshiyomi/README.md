# 星読み毒舌診断

最初は星座を選ぶだけで、性格・仕事・人づきあい・運の動かし方・2026年を読む。もっと詳しく知りたい人は、生年月日・時刻・出生地から西洋と東洋の四つの占いを出す。**図星を、笑える毒舌で日本語にする**静的サイト。

入口は二段階。

1. **まずは星座だけで毒舌診断。** 誕生日入力なし。12星座から選ぶ。
2. **もっと詳しく診断。** 生年月日・時刻・場所を入れ、西洋と東洋を個別に計算する。

占いのページが読みにくい理由を絞って、そこだけ直してある。

1. 記号（♈ ☌ 甲子）ではなく日本語で書く。チャート図の星も「日 月 水 金 火 木 土 天 海 冥」の漢字。
2. **本文に専門用語を出さない。** 用語は表と小さいラベルにだけ残し、本文は日常語だけで書く。
3. **必ず具体例を入れる。** 「たとえば」の無い解釈文は、まだ書き直せる。
4. **怖い用語を画面に出さない。** 「死」「絶」「墓」「空亡」「天中殺」は意味だけ書く。十二支も「午」ではなく「馬」。
5. 読む順番と量を決めてある。最初に見えるのは西洋なら3つ、東洋なら2つだけ。残りは全部たたんである。
6. 毎回「**何を／どうやって／どこで**」の3点セットを明示する。

この6つは [tests/test-wording.js](tests/test-wording.js) が機械的に見張っている。文章を足したら走らせること。

## 毒舌診断の文章

標準表示は、以前の毒舌とギャグを合わせた「毒舌診断」。図星を具体的な場面で突き、短いツッコミで笑わせ、最後に逃げ道を残す。落ち込んでいる人向けに「やさしく読む」への切り替えも残してある。

毒舌診断は「まず読むところ」に85本ある（西洋の3つ＝36本、生まれた日＝10本、宿＝27本、2026年の12星座別＝12本）。星座だけの一般診断には、仕事・人づきあい・運の動かし方・調子の戻し方を12星座ぶん追加している。折りたたみの詳説は共通。

毒舌の設計ルールは3つ。

1. **汎用の悪口を書かない。** その配置でしか言えないことだけを突く。当たらない毒舌はただの悪口になる。
2. **人格を否定しない。** 突くのは癖と行動だけ。
3. **必ず逃げ道（`out`）で終わる。** 中辛はここで一本道を残すから成立する。`out` が無い項目はテストで落ちる。

毒舌診断は同じ図星を、行動が目に浮かぶ場面と短いツッコミで笑える言い方にする。見た目や年齢などの属性、人格、実在の人物や作品は笑いの材料にしない。

選んだ読み口は localStorage に残り、単体ページとも共有される。

内部では従来の `gag` データ名を互換のため残している。文章の構造と合格条件は [SPEC-gag-tone.md](SPEC-gag-tone.md) と `tests/test-gag.js`。

タブは4つ。**西洋**／**東洋**／**東西の対照**／**2026年**。

## 気になるところ（テーマ別）

タブのひとつ。**恋愛と人との距離／仕事と役割／お金の使い方**の3つを、選んだときだけ出す。
並べないのは「一度に見える量を増やさない」という方針を守るため。

新しい占いを足したのではなく、いま出ている材料からそのテーマを担当する星・場所・柱だけを
抜き出して並べ直している（`assets/theme.js`）。主役はテーマごとに違う。

| テーマ | 主役 | 場面 | 東洋側 |
| --- | --- | --- | --- |
| 恋愛と人との距離 | 金星 | 5・7 | 夫妻宮、日柱（伴侶の座） |
| 仕事と役割 | 火星 | 6・10 | 官禄宮、月柱、正官・偏官 |
| お金の使い方 | 金星（別の面） | 2・8 | 財帛宮、正財・偏財 |

文章は `assets/theme-text.js` に72本（3テーマ × 12星座 × やさしい／毒舌）。

**恋愛は断定しない。** 「いつ結婚できる」「運命の相手はこういう人」は書かない。
書くのは「どう近づくか・どこでつまずくか」まで。テストが言い切りの語を弾いている。

## 相性を見る（別ページ）

`aishou/` に2人分を入力するページ。**点数はつけない。** 良い悪いではなく、
どこで噛み合ってどこでずれるかだけを書く。三つの流儀で読む。

- **宿曜の三九の秘法** … 自分の宿を0として、9番目が業、18番目が胎。その各起点から
  栄・衰・安・危・成・壊・友・親が続く。**行きと帰りで関係が変わる**のが本質で、画面でも左右に並べる。
- **四柱推命の日柱どうし** … 上の記号の関係（干合・同じ性質・与える・受け取る・押す・押される）と、
  下の記号の関係（支合・冲・三合）。
- **西洋のシナストリー** … 2人の星どうしの角度。太陽×月、金星×火星の順に重く見る。

三九の秘法の模型は自己検証できる。距離 d の相手から見た自分は距離 27−d なので、
関係は必ず対になるはず（栄↔親、衰↔友、安↔壊、危↔成、業↔胎、命↔命）。
`tests/test-aishou.js` が **27×27の全729通り**でこの閉じ方を確かめている。

## そらと暦のしくみ（読み物）

`shikumi/` に、天体の動きと暦のしくみを説明する別ページがある。目次つきの1枚もの、3章立て。

- 第1章 空のしくみ … なぜ星座は12か／星占いの牡羊座と空の牡羊座は別物（歳差）／なぜ逆行するか／なぜ時刻で場面が変わるか／なぜ食は年4回か／なぜ外の星は世代の話になるか
- 第2章 暦のしくみ … なぜ年の始まりが立春か／なぜ節気の日付がずれるか／なぜ閏月があるか／なぜ宿は27で星座は12か／なぜ真太陽時が要るか
- 第3章 どこまでが計算で、どこからが解釈か

**図13枚はすべて、そのページの中でその場で計算している。**手描きのSVGは一枚もない。
計算部分は `shikumi/shikumi-calc.js` に分けてあり、`tests/test-shikumi.js`（41項目）が
教科書の値と突き合わせる。歳差50.29秒角/年、朔望月29.5306日、恒星月27.3217日、均時差の振れ幅など。

この分離をした理由は事故があったから。`Date.UTC(1, 6, 1)` は**西暦1年ではなく1901年**になる
（0〜99は1900年代として扱われる）。そのせいで歳差が「28度」ではなく「1.7度」と表示されていた。
記事として成立しなくなるので、数値はテストで固定してある。

## 計算について

天体位置は [astronomy-engine](https://github.com/cosinekitty/astronomy)（MIT License, Don Cross）。それ以外は自前。

### 西洋

- 黄経は**その時点の春分点を基準にしたトロピカル方式**（ECT フレーム）。
- ハウスは**プラシーダス方式**。高緯度で成立しない場合はホールサイン方式に落ちる。
- 逆行は前後12時間の黄経を比べて判定。
- 世代天体どうしのアスペクトは、同世代全員に共通で個人の読みにならないため除外。

### 東洋

- **節気は節入り表を使わない。** 太陽黄経が15度の倍数になる瞬間をその場で求めている。
- **年と月は節入りの「瞬間」で切る。** 2025年の立春は2月3日23時10分なので、同じ日の22時生まれは前年（甲辰）扱いになる。
- **日の干支**は (ユリウス通日 + 49) mod 60。日界は入力した日付の0時。
- **旧暦**は冬至を含む月を11月とし、11月から次の11月までが13か月なら中気を含まない最初の月を閏月にする（現行の置閏法）。日界は日本標準時。
- **真太陽時**は太陽の時角から直接出しているので、経度差と均時差の両方が一度に入る。時柱を決めるのに使うかどうかは入力欄で切り替えられる。
- **宿曜**は月宿傍通暦（旧暦の月ごとに1日の宿が決まっていて、そこから日数ぶん進める）。
- **1948〜1951年の日本の夏時間**は自動で +1 時間する（西洋・東洋の両方に反映される）。

### 2026年の運勢

12星座別と、出生図ベースの個別。**ハウスをどこから数えるか**だけが違うので、文章は共通で使い回している。

- 12星座別は、太陽星座を1室として数える（ソーラーサイン方式）。雑誌の星占いと同じ数え方。
- 個別は、アセンダントから始まる実際のハウスで数える。時刻不明なら自動でソーラーサインに落ちる。
- 同じ画面に両方出るので、食い違ったときはどちらが正確かを画面に明記している。
- 2026年に起きることの日付は `y2026.js` の定数だが、`scanYear()` で計算し直せるようにしてあり、テストが両者の一致を確かめている。**別の年を足すときも同じ手順で作れる。**
- トランジットの走査は前年11月から翌年3月まで広げてある。年の境目でぴったりになる角度を「1月1日ごろ」に丸めないため。ピークが2026年の外にある場合はそう書く。

### 流派が割れるところ（このページが採った側）

| 論点 | 採った側 |
| --- | --- |
| 23時台生まれの日柱 | 0時で変わる（日本で多い方）。23時を翌日とする流派もある |
| 紫微斗数の閏月 | 前の月として扱う |
| 九星の日命星 | 陽遁・陰遁の起点が流派で割れるため、出していない |
| 五行の数え方 | 天干と地支を1つずつ。蔵干は数に入れない |

### 分かっている限界

日本の外で生まれた場合、旧暦だけ日本時間で組んでいるため、朔や中気が現地の深夜をまたぐ日だと現地の旧暦と1日ずれることがある。ずれると宿曜の本命宿と紫微斗数の紫微星の位置が変わる。四柱推命と九星気学は節気の瞬間で判定しているので影響を受けない。画面にも同じ注意が出る。

## 決めごと

- **入力した情報はブラウザの外に出ない。** 計算は全部クライアント側。サーバーに送る処理は一つも書いていない。前回の入力は localStorage にだけ残る。
- **断定しない。** 「〜になる」ではなく「〜が出やすい」で書く。当たっていないと感じたらそちらが正しい、とフッターに明記してある。
- **使った暦を隠さない。** 東洋は暦の解釈で結果が変わるので、節入りの瞬間・旧暦・真太陽時・使った刻を全部画面に出している。
- **医療・法律・お金の判断の代わりにしない。**

## これから足すなら

- **2027年** — `y2026.js` を複製して定数を差し替え、`scanYear(2027)` で検算するだけ。文章は `BY_HOUSE`（星×12ハウス48本）をそのまま使い回せるので、書き足すのは4つの節目の総論と12星座別のまとめだけで済む。
- 今日・今月の運勢 — 月の運行と水星。トランジットの土台はもう出来ている。
- 相性 — 西洋はシナストリー、東洋は宿曜の三九の秘法。`calculate()` と `build()` を2回呼ぶだけ。
- 大運・年運（四柱推命） — 節入りからの日数で立運を出す。`setsuMonthAt` がそのまま使える。
