### 2-2. 読み口の切り替え（いまの実装）

`assets/text-spicy.js` の末尾に、こう書いてある。

```js
window.HOSHI_TONE = {
  value: 'soft',
  isSpicy: function () { return this.value === 'spicy'; },
  set: function (v) { /* 'spicy' 以外はすべて 'soft' に丸める。localStorage に保存 */ },
  restore: function () { /* localStorage から読む */ }
};
```

いまは **2値しか扱えない**（soft か spicy か）。ここを3値に広げるのが今回の作業のひとつ。

保存キーは `localStorage['hoshiyomi.tone']`。本体と単体ページで共有している。

描画側は3か所でこれを参照している。

| ファイル | 行のあたり | いまの書き方 |
| --- | --- | --- |
| `app.js` | `pick()` 関数 | `window.HOSHI_TONE.isSpicy() && spicy ? spicy : soft` |
| `app-toyo.js` | `spicy()` 関数 | `window.HOSHI_TONE.isSpicy() ? window.HOSHI_TEXT_SPICY : null` |
| `app-y2026.js` | `sectionSummary()` | `window.HOSHI_TONE.isSpicy() && window.HOSHI_TEXT_SPICY ? ... : null` |

### 2-3. 差し替えの対象は「まず読むところ」だけ

### 2-4. データの形（毒舌版と完全に同じにすること）

```js
window.HOSHI_TEXT_GAG = {
  core: {
    sun:  [ {catch:'', body:'', out:''}, ... 12個 ],   // 牡羊座から魚座の順
    moon: [ ... 12個 ],
    asc:  [ ... 12個 ]
  },
  NISSHU: {                                            // 鍵は 甲乙丙丁戊己庚辛壬癸
    '甲': {catch:'', body:'', out:''}, ... 10個
  },
  SHUKU: {                                             // 鍵は27宿。※ここだけ短い名前
    '昴': {c:'', b:'', o:''}, ... 27個
  },
  SIGN_SUMMARY: [ {catch:'', body:'', out:''}, ... 12個 ],  // 牡羊座から魚座の順
  NOTICE: ''                                           // 切り替えたときに上部に出る注意書き
```

- `catch` / `c` … 見出し。1行。10〜25字くらい。
- `body` / `b` … 本文。

- 配列の並びは牡羊座→魚座。`NISSHU` と `SHUKU` の鍵は、`toyo-text.js` の `NISSHU` / `SHUKU_TEXT` とまったく同じ文字を使う。

**`SHUKU` だけ鍵名が `c/b/o` なのは既存の毒舌版に合わせるため。** 変えると描画側が壊れる。

## 3. やること

### 3-1. `assets/tone.js` を新規作成し、切り替えを3値に広げる

`text-spicy.js` の末尾にある `window.HOSHI_TONE = {...}` のブロックを**そのファイルから削除し**、新しい `assets/tone.js` に移したうえで、次の形に書き換える。

```js
/* 読み口の切り替え。どの描画コードからも参照する。 */
window.HOSHI_TONE = {
  value: 'soft',
  TONES: ['soft', 'spicy', 'gag'],

  /* いまの読み口に対応する差し替えデータを返す。やさしいなら null。 */
  pack: function () {
    if (this.value === 'spicy') return window.HOSHI_TEXT_SPICY || null;
    if (this.value === 'gag') return window.HOSHI_TEXT_GAG || null;
    return null;
  },

  /* 既存コードとの互換のため残す */
  isSpicy: function () { return this.value === 'spicy'; },

  set: function (v) {
    this.value = (this.TONES.indexOf(v) >= 0) ? v : 'soft';
    try { localStorage.setItem('hoshiyomi.tone', this.value); } catch (e) { /* 保存できなくても支障はない */ }
  },

  restore: function () {
    try {
      var v = localStorage.getItem('hoshiyomi.tone');
      if (v && this.TONES.indexOf(v) >= 0) this.value = v;
    } catch (e) { /* 読めなくても支障はない */ }
    return this.value;
  }
};
```

知らない値を渡されたら `soft` に丸めること（テストで確認される）。

### 3-2. `assets/text-gag.js` を新規作成する

上の 2-4 の形で85本書く。文体は §4。ファイル冒頭のコメントに、他のテキストファイルと同じように書き方のルールを残しておくこと。

`NOTICE` は例えばこんな調子で（そのまま使わず、書き直してよい）：

> いまはギャグで読んでいます。当たっていたら笑って、外れていたら鼻で笑ってください。ふざけて書いてありますが、元にしている計算はまじめです。落ち込んでいるときは、上の切り替えで「やさしい」に戻してください。

### 3-3. 描画側3ファイルを `pack()` 経由に直す

**`assets/app.js`** — `pick()` を書き換える。

```js
/* 読み口に応じて、差し替え版があればそちらを使う */
function pick(soft, key1, key2) {
  var p = window.HOSHI_TONE && window.HOSHI_TONE.pack();
  var alt = p && p[key1] && (key2 == null ? p[key1] : p[key1][key2]);
  return alt || soft;
}
```

呼び出し側（`renderCore()` の中）も合わせて直す。いまは `SP && SP.core.sun[sun.sign]` のように毒舌版を直接見ているので、そこを `pack()` から取るようにする。**関数の形は上の通りでなくてよい。要は「毒舌版だけを見ている箇所を、いまの読み口のデータを見るように変える」こと。**

**`assets/app-toyo.js`** — `spicy()` 関数を書き換える。

```js
/* 読み口に応じた差し替えデータ。やさしいなら null。 */
function override() {
  return (window.HOSHI_TONE && window.HOSHI_TONE.pack()) || null;
}
```

`renderNisshu()` と `renderShukuyo()` の中で `spicy()` を呼んでいる箇所を `override()` に置き換える。

**`assets/app-y2026.js`** — `sectionSummary()` の冒頭を書き換える。

```js
var p = window.HOSHI_TONE && window.HOSHI_TONE.pack();
var sp = p && p.SIGN_SUMMARY ? p.SIGN_SUMMARY[sunSign] : null;
```

## 4. 文体ルール（ここが本題）

### 4-1. 守ること

1. **図星を土台にする。** ギャグは、当たっているから笑えます。汎用のボケは効きません。その星の配置でしか言えないことを、おかしく言ってください。毒舌版がすでに図星を突いているので、**同じ的を、笑える言い方で撃つ**のがいちばん近道です。
2. **目に浮かぶ場面を1つ入れる。** 抽象的な誇張ではなく、絵にする。
   - 悪い例：「あなたは宇宙一の心配性」
   - 良い例：「送信ボタンを押したあと、3回読み返してから誤字を見つける」
3. **ツッコミのリズムで書く。** 長い文で振って、短い文で落とす。
   本文には **3文以上**、そのうち **25字以内の短い一文を最低1つ** 入れること（テストで確認される）。
4. **逃げ道（`out`）で必ず終える。** 笑わせたあと、一本道を残す。ここが無いとただの悪口になります。
5. 用語を出さない・一文90字以内。既存ルールの継続です。

### 4-2. 書いてはいけないもの

| 禁止 | 理由 |
| --- | --- |
| 見た目・年齢・性別・収入・学歴・家族構成・病気をいじる | **属性ではなく行動を笑う。** 属性いじりは笑いではなく差別になる。テストで語句を弾いている |
| 人格を否定する語（最低・クズ・無能・バカ・終わってる など） | 毒舌版と同じ方針。突くのは癖と行動だけ |
| 流行語・ネットスラング | 半年で古くなる。読み返したときに寒い |
| 実在の人物・作品・商品の名前 | 権利の問題と、鮮度の問題 |
| 命令形の説教（「〜しろ」「〜やめろ」） | 笑いではなく攻撃になる。`out` は「〜してください」で終える |

### 4-3. 見本（同じ箇所を3段階で）

**西洋・太陽・魚座**

| 読み口 | 見出し | 本文（抜粋） |
| --- | --- | --- |
| やさしい | 線を引かないから、通じてしまう人 | 相手の感情が、そのまま自分に入ってきます。だから察しがよく、だから消耗します。たとえば、機嫌の悪い人が同じ部屋にいるだけで疲れる。 |
| 毒舌 | 線を引くのを、サボっていませんか | 人の気分を勝手に持ち帰ってきては、疲れたと言っています。誰も頼んでいません。 |
| **ギャグ** | **他人の感情を拾い食いしすぎ** | 道に落ちている他人の機嫌を、いちいち拾って持ち帰ってきます。誰も届けてくれと言っていません。カフェで隣の席が揉めているだけで、なぜかこっちがダメージを受けている。そして家で「今日は疲れた」と言う。その疲れ、半分は他人のぶんです。 |

ギャグ版の `out`：**まあ、その拾い癖から作れるものはあります。拾うのは一日三つまでにしてください。**

**西洋・太陽・山羊座（ギャグ）**

- `catch`：努力の総量で、静かにマウントを取る
- `body`：近道した人に「すごいね」と言いながら、心の中で「でも土台がない」と処理しています。口癖は「まだ足りない」。20年やって足りないなら、いつ足りるんですか。褒められると「いや、まだ7割で」と自分で勝手に減点して返してきます。誰も検算していません。
- `out`：ただ、積んだものが崩れないのは本当です。たまには10割ってことにしておいてください。

**西洋・アセンダント・獅子座（ギャグ）**

- `catch`：本人だけが「普通にしてる」と思っている
- `body`：部屋に入った瞬間、なぜか全員がちょっと姿勢を正します。あなたは普通に座っただけです。しんどい日も「余裕そう」で片づけられ、誰も心配してくれません。初日に「頼りにしてます」と言われて断れず、いまも荷物を持っています。
- `out`：その代わり、期待は燃料になります。無理なときは、無理そうな顔をしてください。

**東洋・生まれた日・己（ギャグ）**

- `catch`：畑に、勝手に人が種を植えていく
- `body`：「ちょっといい？」で始まる話を、断ったことがありません。一度もです。気づけば自分の仕事が全部あとに回っている。しかも後日「私も忙しかったんだけどね」と、ちいさく恩を売る。それ、聞いているほうは全部わかっています。
- `out`：ただ、育てる力は本物です。何を植えるかだけ、自分で決めてください。

**東洋・宿・角（ギャグ）** ※`SHUKU` は鍵が `c/b/o`

- `c`：全方位にいい顔をして、渋滞を起こす
- `b`：誰にでも合わせるので、予定が四重にブッキングしています。全部本気だと言い張るのが、いちばんたちが悪い。断らないのは優しさではなく、その場をしのいでいるだけでは。
- `o`：それでも、人が集まるのは本物です。

**2026年・牡羊座（ギャグ）**

- `catch`：「動けばなんとかなる」が効かない年
- `body`：2月から、あなた自身の場所に重い星が29年ぶりに座ります。勢いで押し切る作戦が、今年は通じません。しかも1月末から「自分って何者？」の霧も出ます。答えを急いで出そうとすると、だいたい変な方向に走ります。走ってから気づくのがあなたです。
- `out`：6月末からは、作ることと遊ぶことが息継ぎになります。それまでは耐える年です。

## 7. 補足

### 毒舌を残さず、ギャグに置き換えたい場合

この仕様は「3つ目を足す」前提で書いてある。もし毒舌をやめてギャグ1本にするなら、`tone.js` の `TONES` から `'spicy'` を外し、ボタンを差し替えるだけでよい。`text-spicy.js` は残しておけば、あとで戻せる。

### 4つ目以降を足したくなったら

`tone.js` の `TONES` に名前を足し、`pack()` に1行足し、`text-<名前>.js` を同じ形で作り、HTML にボタンとスクリプトを足す。それだけで増える設計にしてある。
