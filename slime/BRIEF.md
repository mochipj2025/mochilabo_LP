# 十二景スライム 制作概要

## 最重要 — 参照画像を必ず見ること

**渡した参照画像を必ず開いて確認してから描くこと。記憶や想像で描かない。**

- 参照画像が唯一の正解。この文書の文章説明と食い違った場合は、**画像を優先する**。
- 12枚すべて、毎回同じ参照画像を見直してから描く。前に描いた自分の絵を基準にしない（少しずつずれていくため）。
- 体の形・色・目・口・頬・線の太さは、参照画像から一切変えない。

生成側へそのまま渡す指示文：

```
You MUST open and look at the attached reference image before generating anything.
The reference image is the single source of truth for this character.
If this brief and the reference image disagree, follow the reference image.
Look at the reference image again before every single one of the 12 images -
do not base a new image on a previously generated one, or the character will drift.
```

## 何を作るか

同じスライムのキャラクターを12枚。1体が12の状態を通過する形で、**別々のキャラを12種類作るのではない**。

参照画像はクマのフードを被っているが、**フードは外す**。被り物・帽子・衣服は一切なし。

素体（体・顔・線）は12枚とも完全に同じ。変えるのは **頭の上に生えるもの** と、一部の回だけ **体の変形** のみ。

| サイズ | 1024×1024（正方形） |
| 背景 | **完全透過**（白い箱・地面・影を描かない） |
| キャラの占有 | 画面の約77%、中央、正面向き |
| 形式 | PNG |

## 崩れやすい点（生成後にここだけ見る）

1. **体が細長い円錐になる** — 特に「若木」。頭の植物に引っ張られて体まで縦長になる。体の形は絶対に変えない
2. **ピンクが灰色に落ちる** — 特に「満開」。花びらと頬が白〜灰になっていないか確認する
3. **サイズがばらつく** — キャラの大きさが枚ごとに変わると、切り替えたときに飛んで見える。揃っているか並べて確認する

## 補足

既に7枚（芽・双葉・蕾・実り・色づき・風・種）が [wip/](wip) にある。作り直す場合の見本として使えるが、**参照画像より優先させないこと**。

星読みの `hoshiyomi/assets/zodiac/*.png` は同じキャラのフード付き12枚。体と顔の描き方の追加見本になる。
