# 五色 本文（5本）

書き方のきまりは [TEXT-junikei.md](TEXT-junikei.md) と同じ。
色の名前は青・赤・黄・白・黒だけを出す。本文に木・火・土・金・水の比喩を入れない。

## この層が担当すること

日干の五行。四柱推命では日干が本人そのものなので、ここは**何でできているか**を担当する。

- **色** … 何でできているか（質）
- **景** … いまどの段階か（量）
- **星** … どこへ向くか（向き）

三つとも出どころが違うので、話題が被らない。

読む順番は **景 → 色 → 星 → ズレ**（絵と名乗りが景なので、最初に読むのも景にする）。

## 色ごとに起こる景は6つだけ

| 色 | 五行 | 起こりうる景 |
|---|---|---|
| 青 | 木 | 双葉・蕾・実り・落ち葉・風・根 |
| 白 | 金 | 双葉・蕾・実り・落ち葉・風・根 |
| 赤 | 火 | 芽・若木・満開・色づき・土・種 |
| 黄 | 土 | 芽・若木・満開・色づき・土・種 |
| 黒 | 水 | 芽・若木・満開・色づき・土・種 |

青と白の人に満開は来ない。赤・黄・黒の人に風は来ない。
鉢の色が五色を担当するので、画像は 5色 × 6景 = 30枚で足りる。

---

## 青

納得できないことを、納得しないまま進めるのが苦手だと思います。やること自体は嫌じゃないのに、「なぜこれをやるのか」が分からないと体が動かない。理由を聞いただけなのに、反抗していると取られたことも、たぶんあります。

あなたは方向さえ決まれば、あとはいくらでも進める人です。だからこそ最初の向きにこだわる。ここを間違えると全部無駄になると分かっているので、慎重になります。

そのせいで理屈っぽいとか、面倒な人だと思われます。実際は逆で、早く動きたいのに動けなくて、自分がいちばん困っているんですよね。

納得できないものは、三日だけやってみてください。それでも駄目なら降りていい。あなたの場合、やってみると理由のほうが後から見えてきます。

## 赤

あなたが話すと伝わる。同じ内容でも、他の人が言うより届く。場が明るくなるとか、聞いていて元気が出ると言われたことが、何度もあると思います。

ただ、その勢いが続きません。始めたときの立ち上がりが自分でも怖いくらいなのに、しばらくすると急に気持ちが引く。飽きたわけではなくて、上がるのが速いぶん、下りるのも速いだけです。

周りからは調子がいい人、続かない人だと思われがちです。悔しいのは、毎回ちゃんと本気だったことなんですよね。嘘をついた覚えは一度もない。

勢いがあるうちに、いちばん面倒なところだけ先に片付けてください。気持ちが引いてから戻ってくるのは、あなたには無理です。

## 黄

なぜか相談されることが多いと思います。特に何かをしたわけでもないのに、人が話しに来る。そのわりに、自分のことは誰にも話していない。

あなたは相手の話が終わるまで待てる人です。途中で口を挟まないし、結論を急がせない。これができる人は少ないので、自然と人が集まります。間に立って両方の言い分を聞く役も、たぶん何度もやってきましたよね。

ただ、何を考えているか分からないと言われることがあります。抱えている量が多いのに外に出さないので、外からは何もないように見えてしまう。

相談されたときに、自分の話を一つだけ先にしてみてください。聞くのが上手なあなたに足りないのは、聞いてもらう側の経験です。

## 白

曖昧なまま置かれるのが、たぶん一番しんどいと思います。良いか悪いかはっきりさせたい。返事が来ないくらいなら、断られたほうがまだ楽。この感覚は、意外と人に伝わりません。

あなたは決めないまま抱えることに、人の何倍も体力を使います。だから早く白黒つけようとする。冷たいからではなくて、宙ぶらりんに耐えられないからです。

そのせいで、厳しいとか容赦がないと言われることがあります。実際は、早く楽になりたいだけなんですよね。相手を突き放したいわけではない。

決めなくていいものを入れておく場所を、一つ作ってください。全部に決着をつけようとすると、あなたの場合は決着のほうが先に尽きます。

## 黒

どんな場所でも、それなりに合わせられると思います。相手によって話し方も変わるし、その場に必要な役をなんとなく引き受けてしまう。器用だと言われる一方で、本当の自分がどれか分からなくなる時期もあったはずです。

あなたは形を決めないほうが動きやすい人です。決めてしまうと、そこから外れたときに困る。だから最初から固めずにおく。これは処世術ではなくて、もともとの動き方です。

そのぶん、掴みどころがないとか、何を考えているか分からないと言われます。深く考えているのに、その中身をほとんど外に出していないので、当然といえば当然なんですよね。

一人だけ、合わせない相手を作ってください。全員に合わせられるあなたにとって、合わせない相手は休憩場所になります。
